## 🛠️ Track 1: The Developer Perspective (Engineering & Architecture)

Underneath the harmonic interface lies a **high-performance, decentralized Python and Flask architecture** designed for low-friction data flow:

### Core Components

#### **Hexagonal Swarm Routing**
Nodes are mapped onto a 3D coordinate grid using axial/hexagonal addressing. This optimizes decentralized path-finding, minimizing routing hops and network latency across the mesh.

```python
from castleberry.lattice import HexagonalGrid
grid = HexagonalGrid(layers=10, resonance_freq=528)
route = grid.find_path(origin, destination)
```

#### **Entropy Transmutation (Data Normalization)**
What is framed as "transmuting entropy" functions programmatically as an **automated data-normalization and error-correction pipeline**. Inbound noise is reframed as signal through our CML validator.

#### **Coherence Metrics**
The system tracks real-time synchronization scores (0% to 100%) representing:
- Packet integrity
- Node latency
- Consensus health
- Harmonic resonance alignment

#### **Sovereign Stack**
- **Language:** Python 3.11+
- **Framework:** Flask + FastAPI
- **Real-time:** WebSockets
- **Parser:** Custom CML (Castleberry Markup Language)
- **Deployment:** Docker + Kubernetes
- **Cloud:** Fly.io, AWS, or self-hosted

## 🚀 Quick Start

### Installation

```bash
git clone https://github.com/lovelaceyrae11/coherence_in_economics.git
cd coherence_in_economics
pip install -r requirements.txt
```

### Basic Usage

```python
from castleberry.harmony import CoherenceEngine

# Initialize the engine
engine = CoherenceEngine(freq=528, lattice_layers=10)

# Register nodes
engine.register_node(id="node_1", position=(0, 0, 0))
engine.register_node(id="node_2", position=(1.5, 2.6, 0))

# Route a message
route = engine.find_coherent_path(
    source="node_1",
    destination="node_2",
    coherence_threshold=0.95
)

# Monitor resonance
metrics = engine.get_coherence_metrics()
print(f"Network Coherence: {metrics['overall_coherence']}%")
print(f"Harmonic Alignment: {metrics['resonance_score']}")
```

### Run Examples

```bash
python examples/basic_routing.py
python examples/multi_agent_demo.py
python examples/harmonic_sync.py
```

### Docker Deployment

```bash
docker-compose up -d
# Access at http://localhost:8000
```
