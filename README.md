# Castleberry Bloom — Sovereign Node Engine

A lightweight, local-first node architecture designed to integrate seamlessly into existing developer workflows.

## Quick Start (Under 30 Seconds)

Get a local sovereign node running on your machine with zero configuration friction.

### 1. Clone & Setup
\\\ash
git clone https://github.com/lovelaceyrae11/coherence_in_economics.git
cd coherence-in-economics
pip install -e .
\\\

### 2. Initialize Your Local Node
Run the node initializer to start your local mesh instance and verify telemetry:
\\\ash
python cml_core/__init__.py
\\\

### 3. Run the Relational Resource Mapper
Test the local data mapping engine:
\\\ash
python relational_mapper.py
\\\
